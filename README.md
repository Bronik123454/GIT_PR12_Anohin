## Описание программы

Программа _проверяет_, что MySQL установлен и работает, и не даёт
продолжить, пока не получит **честный ответ** от сервера.

MySQL — это база данных. В ней можно хранить информацию: имена,
оценки, заказы — что угодно, в виде таблиц.

### Необходимые условия

Что нужно для установки MySQL:
 1. компьютер
 1. права администратора
 1. 5 ГБ свободного места

> [!NOTE]
> Перед началом работы придётся смириться, что `NULL` — это не ноль.
> Это «пусто». Так уж в MySQL заведено.

```sql
-- Проверка: если запрос сработал — MySQL установлен и работает
SELECT VERSION();

-- Создаём базу и таблицу
CREATE DATABASE test;
USE test;

CREATE TABLE people (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20),
    age INT
);
```

> [!WARNING]
> MySQL не проверяет, правда ли вы человек — он просто выполняет
> ваши команды. Если написать `DELETE FROM people;` без `WHERE`,
> удалятся **все** строки. Используйте ответственно.

### Как установить:

|Шаг|Действие|
|--|--|
|1|Скачать установщик с официального сайта mysql.com|
|2|Запустить и нажать «Next» до конца, задать пароль для `root`|
|3|Открыть терминал и ввести `mysql -u root -p`|

### Пример работы:

```sql
INSERT INTO people (name, age) VALUES ('Арина', 20);
SELECT * FROM people;
```

Ожидаемый вывод:

```
+----+-------+-----+
| id | name  | age |
+----+-------+-----+
|  1 | Сергей |  20 |
+----+-------+-----+
```
